# Meteorología horaria

Las series horarias del dominio van acá con el formato estándar (sección 2.3):

`timestamp,temp_c,hr_pct,viento_kmh,viento_dir_deg,precip_mm,fuente`

Por ahora cada caso de `conjunto_prueba/` trae su propia serie (`meteo_horaria.csv`). Las series de escenarios
operativos (REM / SMN / pronóstico) se agregan acá y se registran en el manifiesto.
